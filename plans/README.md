# Animation plans

Source of truth for the app UI is `desktop/app/`. Android and web-app copies are generated by the build scripts, so edit the desktop files and rebuild instead of editing copies.

| # | Title | Severity | Status |
| --- | --- | --- | --- |
| 001 | Remove open animation from the search palette, quick search and slash menu | HIGH | DONE (unverified in app) |
| 002 | Fix press feedback: stronger scale and smooth release | MEDIUM | DONE (unverified in app) |
| 003 | Add reduced-motion handling and limit moving hovers to real pointers | MEDIUM | DONE (unverified in app) |
| 004 | Make the page-actions menu grow from its button | MEDIUM | DONE (unverified in app) |
| 005 | Replace `transition: all` on the secondary auth button | MEDIUM | DONE (unverified in app) |

## Recommended order

1. **001** first (biggest feel improvement, rewrites the shared animation rule).
2. **004** and **005** next (single-line edits, independent).
3. **002** after that (touches the press rule and base transitions).
4. **003** last: it adds the reduced-motion block next to the keyframes 001 edits and references the press rule 002 changes.

## Dependencies

- 003 reads best after 001 and 002 but works without them.
- 005 has an extra step if 002 is applied (keep the `transform` transition on the button).
- All five edit `desktop/app/style.css`; run them one at a time, not in parallel.

## Not planned (from the audit)

6. Motion tokens and duration consolidation (LOW)
7. Site hero rollers: stronger curve, no permanent `will-change` (LOW)
8. Site nav dropdown scale-from-origin (LOW)
